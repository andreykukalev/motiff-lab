## Ваша задача (не больше <1200> слов, по-русски)

1. **Смертельные удары.** Для КАЖДОЙ другой позиции 1–3 самых опасных конкретных сценария: пошаговая хронология
   (устройства, сборки, версии, кто что сохраняет, когда), которая кончается одним из плохих исходов:
   <ПЛОХИЕ ИСХОДЫ ИЗ КРИТЕРИЕВ БРИФА>. Оценка: смертельно / серьёзно / терпимо. Никаких «это может быть сложно».
2. **Атака на сходство.** Сильнейший аргумент, что сходство неверно. Не можете сломать — какую его цену никто не
   посчитал. Слепое место начинает с этого пункта и делает его главным.
3. **Решение по каждому разногласию (a)–(…)** одной строкой с причиной.
4. **Что вы бы забрали** из каждой другой позиции.
5. **Уступки.** Какие свои решения раунда 1 вы теперь считаете неверными, в том числе из-за `facts.md`. Адвокат
   уступает только факту, по номеру.

Не читайте репозиторий и другие файлы, кроме `facts.md`, `r1/*.md`, брифа и этого файла.
