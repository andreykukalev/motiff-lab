# Round 1 — independent position

Read `brief.md`, `facts-baseline.md` and, if present, `lenses.md` and the concept the brief names. The blind seat reads
only `brief.md` and `facts-baseline.md`. Read nothing else and write nothing to disk.

Write ONE concrete position. The other seats write independently and will attack yours in round 2, so make it specific
enough to attack: what is shared and in what form, where state lives, who writes it, the versioning rules — with
numbers. An advocate builds the best version of its option.

Required sections (at most <1500> words, markdown, in English):

1. **Name and thesis** in one paragraph.
2. **Each hypothesis of the brief H1…**: holds / breaks (a scenario: actions, data, versions) / costs more than it
   looks (how much).
3. **<DECISION AREA 1 FROM THE BRIEF>**: <WHAT TO NAME>.
4. **<AREA 2…>**
5. **The brief's test scenario**: for each step, the component that performs it.
6. **The path from today's `main`**: the steps in order, whether each can be undone, a first step the size of one task.
7. **Criteria 1–N**: one line each.
8. **What is wrong with your position**: its two weakest points, honestly.
9. **Facts needed**: what `facts-baseline.md` lacked (the moderator checks it before round 2).

Every claim about the code cites `F<n>` or is marked "unverified".
