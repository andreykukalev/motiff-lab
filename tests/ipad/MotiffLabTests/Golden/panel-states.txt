# The score screen's panels: what every action comes to, as the screen's reactions ran it before PanelState (v0.7, B2):
# the present-behaviour table. PanelStateTests runs PanelState against every line; docs/code-map/ipad/workspace.md.
# Changed since only by the lines that Andrei's answers 9 and 10 (2026-11-17, thread «Версия 0.7») fix.
#
# A section is a start state: its name, then the actions that reach it from a fresh screen, then `=` and the state.
# A line is an action the screen offers there and the panels render by render: first as the action writes them, then
# after each render's reactions, until nothing changes. The last is what the action comes to.
#
# A state is the panels open, joined by + (nothing for none), then {what is remembered}: fromMore (the place shows
# "‹ More"; fromMore=… where a place open was not opened from More: the places that were, the others show none),
# rollBeforeFocus and contentsBeforeFocus (given back after Expand), beforeSources=… (given back as Sources
# closes); then [Expand] or [Expand roll] (the card as a roll), and (assistant open).
#
# Actions: open, close; fromMore (Check, Sources or Settings pressed in More); backToMore ("‹ More"); expandFromDrawer
# (Expand on the roll's drawer); enterFocus notes (Expand from the selection menu); enterFocus (focusRoll kept on) (the
# same when the card was last shown as a roll); bookmark to Expand (a bookmark's entry in the Contents pressed again);
# leaveFocus (Back to page, Collapse); focusRoll on, off (Notes | Piano roll on Expand's bar); openDraftFromFocus
# («Открыть в черновике» on Expand's bar: leaves Expand and opens Sources in one step); backToMore dna (Piece DNA's
# "‹ More"); assistant open, close.
#
# 78 sections, 914 lines.
